# SiKeuangan

SiKeuangan adalah aplikasi manajemen keuangan berbasis Laravel (fullstack) yang digunakan untuk mencatat transaksi keuangan dan menampilkan laporan keuangan secara terstruktur.  
Aplikasi ini dikembangkan menggunakan arsitektur Model–View–Controller (MVC), di mana backend dan frontend dijalankan dalam satu environment aplikasi.

---

## Fitur Utama
- Autentikasi pengguna (login dan register)
- Pencatatan transaksi keuangan
- Laporan keuangan
- Manajemen profil pengguna
- Proteksi halaman menggunakan middleware

---

## Teknologi yang Digunakan
- Framework: Laravel
- Bahasa Pemrograman: PHP
- Database: MySQL atau SQLite
- Frontend: Blade Template dan CSS
- Version Control: Git dan GitHub
- Deployment: Railway.app

---

## Arsitektur Aplikasi
Aplikasi ini menggunakan pendekatan fullstack Laravel, di mana:
- Controller menangani logika aplikasi
- Model berinteraksi dengan database
- View (Blade) menampilkan antarmuka pengguna

Seluruh komponen tersebut berjalan dalam satu server aplikasi.
