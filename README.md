# SiKeuangan

SiKeuangan adalah aplikasi berbasis Laravel yang digunakan untuk mencatat transaksi keuangan dan melihat laporan keuangan.  
Aplikasi ini dibuat sebagai latihan sekaligus penerapan konsep Laravel fullstack, di mana backend dan frontend berjalan dalam satu aplikasi.

---

## Gambaran Umum
Aplikasi ini memungkinkan pengguna untuk:
- Login ke dalam sistem
- Mencatat transaksi keuangan
- Melihat data transaksi dan laporan
- Mengelola profil pengguna

Semua fitur tersebut dibangun menggunakan Laravel dengan struktur MVC (Model, View, Controller).

---

## Teknologi yang Digunakan
- Laravel
- PHP
- Blade Template
- CSS
- Database MySQL / SQLite
- Git dan GitHub
- Railway.app untuk deployment

---

## Struktur Aplikasi
- **Controller** digunakan untuk mengatur alur logika aplikasi
- **Model** digunakan untuk mengelola data dan database
- **View (Blade)** digunakan untuk tampilan antarmuka pengguna

Aplikasi dijalankan sebagai satu kesatuan (fullstack), sehingga pengguna dapat langsung mengakses sistem melalui satu alamat web.
